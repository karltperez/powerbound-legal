# Powerbound legal pages

This public repository contains only the Terms of Service, Privacy Policy, and a small index page for the Powerbound combat power archive. The app source remains in the private `powerbound` repository.

After enabling GitHub Pages with the GitHub Actions source, the policy URLs are:

- https://karltperez.github.io/powerbound-legal/terms.html
- https://karltperez.github.io/powerbound-legal/privacy.html

Keep `info@insyc.digital` monitored for privacy and deletion requests. Update both this repository and the app repository if the policies change. Confirm the published pages load publicly over HTTPS before adding them to the Discord Developer Portal.
